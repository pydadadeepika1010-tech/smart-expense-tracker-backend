# 💰 SpendSmart — Smart Expense Tracker & Financial Advisor

**SpendSmart** is a modern, full-stack Web Application built using Python, Flask, and SQLite. It helps users automatically track, categorize, and forecast their personal expenses, manage monthly budgets, and analyze spending habits with an intuitive visual dashboard.

---

## 🌟 Key Features

- 🤖 **Auto-Categorization Engine**: Automatically classifies transactions (Food, Transport, Shopping, Entertainment, Health, Bills, Education) using smart keyword matching.
- 📊 **Interactive Dashboard & Analytics**: Real-time visual summary of income, expenses, net savings, and category-wise breakdowns.
- 📈 **Smart Expense Forecasting**: Predicts total month-end expenditure based on current daily spending velocity.
- 🎯 **Weekly Money Challenges**: 8 gamified savings challenges (*No Takeaway Week, Cash Only Week, 50% Cut Challenge*) to boost savings.
- 💀 **Budget Horror Rating & Meter**: Real-time spending horror classification (*Saint of Savings 😇 ➔ Mildly Cursed 😬 ➔ APOCALYPTIC 💀*).
- 🎵 **Spending Mood & Music Playlists**: Analyzes spending habits and pairs user persona with custom music playlists (*Broke But Make It Fashion 💅, Retail Therapy Patient 🛍️*).
- 🏆 **Financial Verdict Badges**: Custom roasted badges based on transaction patterns (*Zomato Addict 🍕, Cab Connoisseur 🚗, Impulse Buyer 🛒*).
- 💵 **Manual & Cash Expense Logging**: Log out-of-pocket cash expenses (tiffin, auto, groceries) with payment mode tags (`💵 Cash`, `📱 UPI`, `💳 Card`).
- 📁 **CSV & PDF Statement Import**: Upload PhonePe, GPay, or Bank PDF/CSV statements to bulk import transactions.
- 🎯 **Budget Limits & Alerts**: Set custom monthly category spending caps to keep financial goals on track.
- 🔐 **User Authentication & Roles**: Secure login/registration with SHA-256 password hashing and role-based access (User, Admin, Financial Advisor).

---

## 🛠️ Tech Stack

- **Backend**: Python 3.x, Flask Framework, SQLite / SQLAlchemy ORM
- **Frontend**: HTML5, CSS3, JavaScript
- **Security**: SHA-256 Hashing, Session-based Authentication & Route Guarding

## 🚀 Quick Start Guide

### 1. Clone the Repository
```bash
git clone https://github.com/YOUR_USERNAME/spend-smart-expense-tracker.git
cd spend-smart-expense-tracker
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Launch the Application
```bash
python app.py
```

### 4. Access in Browser
Open `http://127.0.0.1:5000` in your browser.
